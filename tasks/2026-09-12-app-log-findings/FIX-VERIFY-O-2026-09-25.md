## Дополнительно обнаружено независимой проверкой O

| ID | Уровень | Результат и проверка |
| --- | --- | --- |
| NO-1 | P3 | `TestCase` не переводит PHP Warning в ненулевой exit code; прежний matcher признавал такой тест зелёным. Адресная PHP-проба дала код 0 со строкой `Warning:`; мини-матрица до правки ошибочно ответила green. Новый общий matcher распознаёт Warning/Notice и оба префикса PHP; та же мини-матрица стала красной, весь `matrix-test.sh` проходит. |
| NO-2 | P3 | При красной ноге и изменении дерева во время проверки прежний digest-маркер оставался зелёным, поскольку отзыв зависел от равенства `before=after`. RED мини-проба сохранила маркер; после безусловного отзыва именно `before` под lock он удаляется. |
| NO-3 | P3 | Удаление Docker-контейнера до остановки `docker run` могло получить `not found`, после чего daemon заканчивал create. Fake Docker с отложенным созданием до правки оставил контейнер; после TERM, короткой паузы, KILL/wait и повторного удаления по уникальному имени не оставляет. Абсолютная гарантия при произвольно долгом асинхронном Docker create не доказана; такие аномалии требуют внешней уборки по имени. |
| NO-4 | nit | `cp -al` делил inode между ногами и экспортом: запись теста в свой файл меняла другие снимки. Мини-проба до правки воспроизвела изменение `export/env_check.php`; `cp -a --reflink=auto` дала независимые файлы, проба и весь `matrix-test.sh` проходят. Текущий экспорт занимает около 26 MiB; четыре копии не создают существенной нагрузки на диск. |
| NO-5 | nit, только локальный hook | Комментарий `.git/hooks/pre-commit` всё ещё описывал старую область digest, а при Warning от runner печатал пустую сводку. Локальный hook теперь называет все экспортируемые не-Markdown файлы и использует общий `PHP_FAILURE_PATTERN`; `bash -n` прошёл. Hook не отслеживается Git и не входит в переносимые коммиты. |
| NO-6 | P3 | Digest учитывал содержимое, но пропускал режим файла: в отдельном Git-репозитории chmod 0644→0755 для отслеживаемого `*Test.php` оставил прежний hash. Значит, локальный pre-commit мог принять сохранённый green-маркер после изменения исполняемости. В `tasks/matrix.sh` добавлен тип/режим к отпечатку каждого пути; мини-проба в `matrix-test.sh` была RED (`chmod missed the digest`) и стала GREEN. |
| NO-7 | P3 | Матрица считала строку `> php ...Test.php` доказательством запуска тестов: изолированный репозиторий с настоящим `tests/php-test.sh` и пустым `aTest.php` дал `exit=0, failures=0, files=1`. В `tests/php-test.sh` добавлена проверка наблюдаемого непустого прогона: `TestCase` требует marker метода и `Passed:`, самозапускающаяся suite — `ok -` и положительный итог `tests?/0 failures`. Тест сначала упал с `empty PHP test file was accepted`, после правки прошёл вместе с настоящими синтетическими примерами обоих стилей. На завершённом локальном логе из 85 файлов критерий принимает все 84 с положительным результатом; единственный не прошедший — уже красный `FetchErrorTest` (9 tests, 1 failures). |
