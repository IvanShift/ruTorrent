## Как проверять

- **Мерить, а не рассуждать.** Каждый вердикт — с приложенной командой и её выводом.
- **Две матрицы PHP:** локальный 8.5 и
  `docker run --rm -v "$PWD":/w -w /w/tests php:8.1-cli bash php-test.sh`.
  **Без `--user`** — именно так написано в README проекта, и именно так тест D0 краснеет.
  С `--user "$(id -u):$(id -g)"` он зелёный, разница принципиальна.
- **Мутационная проверка** каждой правки: вернуть дефект, убедиться, что падает ровно
  ожидаемый тест.
- **Никакого PHPUnit и composer** — в upstream их нет, это жёсткое правило форка.
- Локальный `grep` — обёртка над ugrep с `-I`, молча пропускает бинарный ввод.
  Считать только через `grep -a`.
- После контейнерных прогонов: `sudo chown -R dev:dev .` (в этот раз артефактов не
  осталось, но проверять стоит).
